## Funcion
Este script obtiene información básica del sistema, incluyendo:

- Usuario conectado
- Nombre del equipo (hostname)
- Sistema operativo
- Dirección MAC de la primera interfaz activa

## Ejecucion
### Linux/macOS
- Aprir un reminal
- Navegar al directorio donde se encuentra "info_sistema.sh":
- En caso de no tener, dale permisos de ejecucion: "chmod +x info_sistema.sh"
- Ejecutar el script: "./info_sistema.sh"

### Windows
- Abrir Git Bash
- Navegar al directorio donde se encuentra "info_sistema.sh":
- En caso de no tener, dale permisos de ejecucion: "chmod +x info_sistema.sh"
- Ejecutar el script: "./info_sistema.sh"
